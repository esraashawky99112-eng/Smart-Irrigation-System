# Smart Irrigation System

## Project Overview
An Arduino-based smart irrigation system that monitors soil moisture and water tank levels to control a water pump automatically.

## Features
- Soil moisture monitoring
- Water level measurement using an ultrasonic sensor
- Automatic water pump control
- Low water level buzzer alert
- LED status indicators
